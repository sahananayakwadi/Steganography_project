# Steganography_project
Developed a Steganography project using C to hide secret information inside an image.
Implemented encoding and decoding techniques for hiding and extracting data.
Used bit manipulation and file handling concepts to process image data.
Added validation to ensure the input image and secret data are handles correctly.
Gained practical knowledge of pointers, structures, binary data, and debugging in C.

# Technology Used
Language:C
Concepts:File handling,Pointers,Bit Manipulation,Structures,Functions.

# Learnings
Learned file handling and bit manipulation in C.
